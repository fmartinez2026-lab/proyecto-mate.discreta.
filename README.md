# proyecto-mate.discreta.
calculador-rutas-optimas
En este codigo de 180 lineas, con una interfaz grafica y amigable, se logró crear un calculador de rutas optimas, proyecto que, analiza trayectos entre ciudades, y devuelve el camino más corto posible, este proyecto fue basado en colombia, exactamente en 15 ciudades del paism anteriormente mencionado, las ciudades asociadas al proyecto son las siguientes:

Bogotá
Medellín
Cali
Barranquilla
Cartagena
Bucaramanga
Cucuta
Pereira
Manizales
Santa Marta
Villavivencio
Ibagué
Pasto
Montería
Sincelejo

Como usarlo
Para usar este proyecto, basta con iniciarlo, y en la interfaz que se desplegará ingresar inicio y destino, luego de, se iniciará un gráfico mostrando la ruta más optima

Requerimientos
Para ejecutar este proyecto, es necesario contar con las siguientes librerías:
tkinter
networkx
matplotlib.pyplot
heapq
os
